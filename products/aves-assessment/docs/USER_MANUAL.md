# Aves Assessment — Customer User Manual Baseline

## Access
You can only see Assessments explicitly granted to your account and only during the authorized access period.

## Assessment flow
1. Select the problem you want to solve.
2. Add one or more Sites; add one or more Production Lines inside each Site.
3. Select or complete the Process Flow.
4. Add equipment and known control/interface information.
5. Describe current and desired Data Capturing / Automation / SCADA conditions.
6. Enter the target schedule / go-live timing.

You may leave unknown information incomplete. The platform will lower completeness/confidence and explain which gaps affect the estimate.

## Estimates
A preliminary estimate is a range, not a binding quotation. Missing controller, protocol, network, cybersecurity, validation or integration information may widen the range.

## Light Consulting
If important information is unknown, request Light Consulting so the assessment can be improved before a more reliable quotation is prepared.


## Q3 — Process Flow
For each Production Line, select the Site and Production Line context first. You may then:
- apply an available Admin Process Template;
- review the ordered Process Steps;
- add, edit or delete line-specific Process Steps when allowed.

Your changes affect only the selected Production Line Draft Process Flow. They do not modify the Admin master template.
