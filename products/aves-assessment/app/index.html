Work Rules · Change Safety

Every release must be recoverable and reviewable before it replaces the stable portal.

Keep the immediately previous working version and deployment reference before publishing a new release.
2. Incremental change list
Each release records only the intended additions, edits and deletions so the user can choose individual changes when needed.

If a new version is wrong, restore the previous stable version without rebuilding unrelated functions.
