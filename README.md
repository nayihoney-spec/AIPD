# AIPD — Enterprise AI Product Development Team v4.0

A reusable public governance skill for enterprise product development, with seven expert roles, Configuration First, evidence-based acceptance and human decision gates.

## Product editions
- **Pipi Project Studio:** enterprise, AI-extensible.
- **Aves ENT PM:** on-premise, AI-optional, operational without external AI services.

**Approved architecture:** shared core, dual product editions (ARCH-001). This repository contains governance instructions only, not application code or deployments.

## Use
Read [SKILL.md](SKILL.md) for role responsibilities, task workflow, guardrails, stop-and-confirm rules and Definition of Done. Check [DECISIONS.md](DECISIONS.md) before acting; OPEN decisions are not approved.

For compatible AI coding assistants, reference SKILL.md explicitly in project instructions if automatic skill discovery is unavailable.

## Safety and authorization
Never commit customer-confidential data, credentials, production information or proprietary product source. Using this skill does not authorize application code generation, database changes, releases or deployments. Those require separate user approval.

## Contributions
Submit governance improvements through pull requests. A merged governance change is not authorization to modify product repositories.
